# CVPR 投稿前审阅：论点、CIFAR 失败与下一步实验

2026-10-20。阅读范围：`main.tex` 引入的全部正文与附录、本地 CIFAR 三组完整 summary、固定预算实验的本地训练记录，以及 CIFAR 训练/评估代码的相关实现。使用用户指定的 `H:/anaconda3/envs/py312/python.exe` 重算汇总。未启动新训练、未访问服务器、未重跑区间认证，也未进行新的文献检索。本记录是内容与证据审阅，不代表已完成证明正确性或新颖性验收。

## 1. 总体判断

论文有一条成立且值得继续的研究主线：**参数化与分层更新改变压缩方向，因此预训练目标的改善与独立任务的线性可读性可以分离。** 现稿对 encoder 与 projection 的区分、尺度不变风险、理论与经验条件的边界都写得认真，避免了用正则化 probe 或数值秩混淆几何变化。

但以当前证据投稿 CVPR，我认为主要风险是视觉意义与机制验证之间的缺口。定理是精确构造，纹理实验主要展示子空间位移，自然图像实验主要展示随机压缩的缺口；三者尚未汇成一个足够有力的、可在视觉数据上检验的预测。增加轨迹数量或把 CIFAR 的监督 head 结果写得更正面，不能自动补上这个缺口。

CIFAR 的绝对准确率低并非唯一问题。更关键的是：在当前目标、增强、架构与优化预算下，训练相对随机初始化几乎没有增加类别的线性可读性；同时也未建立自然图像上的稳定风险方向干预。该结论不能唯一归因于 GUPA、浅层模型或学习率，因为现有对照没有分别识别这些原因。

## 2. 本次重新核算得到的关键事实

### 五个确认种子：较好的最终配比没有带来相对初始化的平均提升

种子 2–6；下表全部为同一 5,000 图像验证集的 projection OLS 准确率。初始数值在同种子的配比间相同。

| r | 初始化 % | 4000 步 % | 配对平均变化，百分点 | 最终平均 log-energy |
|---|---:|---:|---:|---:|
| 0.1 | 23.436 | 22.852 | −0.584 | 5.243 |
| 1 | 23.436 | 22.904 | −0.532 | 5.204 |
| 10 | 23.436 | 23.396 | −0.040 | 3.957 |

这补充了正文目前主要报告最终测试准确率的叙述。测试集的 23.39/23.50/23.81% 不能与上表初始验证准确率相减。测试集没有同规则的初始参照，分析训练变化应使用已有的配对验证曲线。

五种子 projection 验证均值在 0/1000/2000/3000/4000 步分别为：

- r=0.1：23.436 / 23.280 / 22.876 / 22.792 / 22.852%。
- r=1：23.436 / 23.320 / 23.300 / 22.928 / 22.904%。
- r=10：23.436 / 23.408 / 23.408 / 23.396 / 23.396%。

当前采样点没有展示均值层面的“先明显改善再显著超过初始风险”的自然图像对应物。不能排除未采样早期过程，也不据此否定存在这种现象。

r=10 的最终能量推进明显较小，且最终 minibatch loss 均值约 −0.312，另两组约 −0.516/−0.511。不同随机批次上的 loss 只提供辅助背景，不是固定审计集上的收敛比较，更不能据此声称逐步单调下降。总体上，“较慢推进保留了更多初始表现”与这些数据相容，但仍不是已识别的因果结论。

已有共同能量 ell=0.5/1/2 的 projection 配比差区间跨零。它们只覆盖训练的较早能量范围；最终状态平均 ell 接近 4–5，不能把早期截面的弱结果当成全程路径等价的证明。

### 三个开发种子：容量提升基本在初始化时就存在

以下均为 r=1 验证准确率，初始化 → 4000 步。

| C/K | encoder % | projection % |
|---|---:|---:|
| 64/8 | 36.313 → 36.040 | 23.493 → 23.707 |
| 256/8 | 43.040 → 43.040 | 23.660 → 23.647 |
| 64/32 | 36.313 → 36.227 | 32.053 → 32.140 |

64/8 的 projection 准确率略升，但验证 one-hot MSE 从 0.08629408 变为 0.08631537，方向相反。论文研究的是平方风险，因此建议把 MSE 与准确率并列；不能用微小 accuracy 差异替代风险方向证据。开发与确认种子也不能混成新的独立确认集。

64/8 的原始协方差谱熵有效秩：encoder 1.979 → 1.097，projection 1.886 → 1.013；设计矩阵含截距的数值秩仍为 65/9。输出总方差约 0.00959 → 1.75460。无监督训练确实显著改变了方差结构，不能简单说模型没有更新；但谱集中也不能单独证明任务信息丢失。

### 冻结 head：最清楚的正面诊断，同时也最容易被过度解释

同一 trained encoder：完整 OLS 36.04%，原 head 23.71%，rank-8 LS 35.59%。存在更好的八维压缩是明确的。可是初始化时对应数值已为 36.31/23.49/35.75%，所以巨大缺口主要先于预训练存在。

十类中心化标签至多九个独立目标方向，因此 rank-8 接近完整 OLS 有直接的低秩回归背景。该结果是“可用压缩”的参照，无法独立承担论文创新，也不能替代无监督干预的证据。

本次通过 1260 个汇总指标的逐种子均值检查，并核对 frozen 与 capacity 中 16 个来源指标的逐种子一致性。计算结果保存在 [审计 JSON](CIFAR_REVIEW_AUDIT_20261020.json)。这些检查不等于独立验收服务器冻结参数、裁剪日志或原始 checkpoint。

## 3. 从现有实现提出的解释与可证伪预测

### 假设 A：训练主要放大容易的二阶统计方向

这是值得首先检验的假设，不是当前结论。对每张图像取 valid patches p_u，则 encoder 第 c 维恰为 h_c^T M(x) h_c，其中 M(x)=平均_u p_u p_u^T。因此当前模型直接读取平均局部二阶矩；没有显式保留 patch 排列，也没有颜色输入。自然图像中高方差的亮度、对比度或纹理统计可能主导优化，但是否发生、是否与类别任务弱相关，尚需测量。

最省算力的检查：在已有 checkpoint 的固定无标签审计图像/增强视图上，记录 alignment、两个 uniformity 项、协方差全谱、每个主成分的方差及跨视图稳定性。另用图像均值、全局 RMS、patch 能量等 nuisance 指标解释主成分，并单独报告类别相关性。仅相关不构成因果解释；若有明确候选，再做预先限定的单因素干预。不要一开始同时改归一化、增强、架构与损失。

### 假设 B：配比主要改变推进速度，几何路径差异很小

共同总能量只能匹配一个标量，不能保证协方差谱、训练目标或方向相同。应在同架构、同种子内补共同能量与共同固定审计 loss 两套比较，同时看任务风险及特征空间位移。两种配准都只是自然图像的进度参照，不是定理中的精确时间重参数化。

对固定审计图像的中心化特征矩阵 F，比较其列空间 projector；这可区分可逆特征坐标变化与样本上的可读函数空间变化。该对象不是 Fourier 系数矩阵的 row space，也不是总体信息量。保留秩、奇异值、阈值敏感性。不能直接将参数夹角或原始协方差变化解释为风险变化。

### 假设 C：监督 CE head 的差距来自优化或评估目标不匹配

CE 用增强视图，rank-8 LS 用 clean 特征，且优化器、标准化、裁剪与目标均不同。若需要解释这个差距，可固定同一 clean 特征、统一平方误差与截距约定，让梯度训练的分解式 head 对照闭式 rank-8 解；先确认训练误差接近解析参照，再讨论优化困难。

这能回答优化诊断，却仍回答不了 CVPR 稿件最核心的自然图像机制问题；建议排在直接机制验证之后。

## 4. 下一轮实验的建议顺序

### 优先级 1：用已有状态做“预测后分支”的直接机制检验

与其要求无标签配比统一提升 CIFAR 分类，不如先验证论文真正声称的 task-conditioned 方向机制。固定若干已有训练状态，明确区分 encoder / projection，并选定一个主要风险终点，预先计算两参数块的风险变化系数，再从完全相同状态执行短程配比分支。

建议把 one-hot 平方风险作为主要终点，accuracy 为次要终点。训练集 profiled OLS 残差的导数可直接计算；验证风险若每次重拟合 decoder，其导数必须包含训练集解随特征变化的影响，不能套用总体 projector 风险公式。用有限差分先核验所选导数。

报告：可形成正临界配比的状态比例、跨阈值实际符号反转、预测/观测量级、分支长度与批次重复影响、以及固定符号基线。状态没有可行阈值时照实保留。这是有标签的 oracle 机制实验，标签只用于风险诊断；不能宣称得到部署时无需标签的配比规则。

先在开发种子限定状态、风险、容差和预算。如果有可复现信号，再冻结协议，使用未参与选型的初始化种子确认；所有分支与 checkpoint 仍按种子汇总。若始终没有可行阈值，得到的是该机制在此配置上的边界，不应继续盲扫配比寻找漂亮曲线。

### 优先级 2：检查目前缺少的晚期共同进度

所有五种子最终都达到 ell>3，但既有 energy checkpoint 只有 0.5/1/2。可用原配置做针对性重跑或从有完整恢复信息的状态续跑，新增 ell=2.5/3 的首次穿越保存与评估；这些截面是在看过旧结果后提出的，应标记为探索性。不能从现有稀疏 checkpoint 插值伪造精确截面，也不能仅有模型权重就声称恢复了随机数流。

在固定审计集上同时分解目标与谱，判断晚期到底有明显方向竞争还是只有大尺度变化。优先用已有架构，不先启动 RGB × 深度 × 宽度的大网格。

### 优先级 3：若目标仍是实际分类收益，再改变训练设置

只有在明确瓶颈后，才对增强、目标或架构做有限单因素检查。监督 Adam 参照排除了“该模型在所有训练下都无法提高”的说法，但不能证明无监督 SGD 充分优化，也不能证明更换任意大 backbone 就会保留定理机制。若改为实用 SSL 方法论文，需要额外建立无标签决策规则及独立验证，这已经超出现稿的定理主张。

## 5. 稿件层面的优先修改

1. **把核心现象画出来。** 目前三张图分别是经验子空间、干预边界与冻结 head，缺少最直接的风险回升图。建议首图展示固定构造的 loss、能量及 projection risk，标出两认证截面和保证；同图或邻图显示 encoder risk 保持噪声底。数值轨迹、区间认证、随机种子实验必须分开标识。
2. **纹理部分补风险证据，而不只报告位移。** 子空间移动并不说明特定任务变坏。给出预先指定主任务的风险路径、相对初始值、配比效应与配对不确定性；其余任务展示异质性。不能把所有任务/截面中挑出的最大回升写成普遍规律。
3. **CIFAR 正文保留关键失败。** 并列报告随机初始化到最终的验证变化、等进度配比结果，以及监督 rank-8 参照。容量表、CE 优化细节与大部分开发诊断可移至补充材料。现有谨慎措辞应保留，但正文需要先交代研究问题与答案，减少连续的限制声明。
4. **不要把信息论表述扩大到线性 probe。** 用“线性可读性/所定义任务风险”解释指标，避免由有限标签 accuracy 推断所有语义信息被保留或丢失。经验 encoder/projector 位移也不能称为总体不变量的直接自然图像验证。
5. **贡献与预测一致。** 当前最有价值的候选组合是：实际参数动态的固定风险间隔认证、encoder 与 projection 空间的区分、可检验的任务条件预测及其失效边界。一般的层间速率敏感性、随机 head 缺口和径向 loss 下的回落不能各自当作新发现。现有文献审计仍有未完成事项，本次未补完它。
6. **最后再做投稿格式。** 当前为通用 article 双栏，作者仍是 Working manuscript，构建记录总计 11 页（含参考文献和附录）。该数字不等于正文页数。本次未核查目标年度 CVPR 正式规则，不能据此声称超页或合规；套用目标会议正式模板后应单独核验匿名、正文长度与补充材料组织。

## 6. 当前建议

保留理论主线，暂不把 CIFAR 包装为成功外推。下一笔算力优先投入已有 CIFAR 状态上的局部机制预测与分支验证，先回答“模型能否按理论预期改变所定义任务的风险方向”。若结果仍弱，论文应以受控机制与边界为定位，并承认 CVPR 的视觉实证说服力仍不足；单靠删掉负面实验或增加监督 head 表格无法解决。
