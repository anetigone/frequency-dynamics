## 1. 完整经验训练确实到达具有相同结构信号的状态

主配置 d=16、C=8、K=1，独立无标签校准，有限训练集 32,768，batch=256。
全支撑和局部共 180 条主轨迹均到达预设公共能量 ell=1.5；数值秩保持 encoder=8、projection=1。

| 模型 | r=0.1 的 encoder 位移 | r=1 | r=10 |
|---|---:|---:|---:|
| 全支撑平方 | 0.41312 | 0.13692 | 0.01843 |
| 全支撑线性 | 0.02336 | 0.00666 | 0.00089 |
| 全支撑冻结前层 | 0 | 0 | 0 |
| 局部平方 | 0.44250 | 0.17740 | 0.02626 |
| 局部线性 | 0.02851 | 0.00920 | 0.00123 |

位移为相对初始行空间正交投影的 Frobenius 距离，以上为十种子均值。
完整十任务风险差、固定 4000 步结果、各能量截面和逐种子结果全部保存，未挑选单条 U 形曲线。

复用既有总体 checkpoint 作只读比较，没有新增总体积分：r=1、ell=1.5 时，
全支撑经验/总体 encoder 投影之间距离均值约 0.00713，而经验 encoder 自身位移约 0.13692；
局部对应数值为 0.00850 与 0.17740。
这比仅从总体训练状态分叉更直接地支持完整经验轨迹到达相近几何状态。
它仍是有限模型族的数值结果，差异包含数据、批次和离散步长效应。

## 2. 线性移动具有可重复成分，不能都归为零均值噪声

固定初始化及训练集，三条独立批次/增强流的末端 Delta P 两两余弦先按种子平均，
再汇总十种子：平方为 0.9810，线性为 0.8683。
这表示给定初始化和数据的方向可重复，不表示不同初始化都偏向同一固定频带。

batch 增大时条件方差明显减小，但线性的大 batch 平均移动不必归零。
探索性条件矩参考进一步解释了这种偏移：固定有限训练集的功率协方差通常不为 I，
将该条件视图矩代入 GUPA 后，线性前层不再只作保持行空间的左乘。
两个开发状态的线性大 batch 平均位移都更接近条件矩参考，而非各向同性零位移。

这是事后解释诊断，不是新预测器的独立确认；有限 batch 非线性矩估计与有限步长也会贡献偏移。
总体行空间守恒的严格前提及原主定理 T 均保持原有边界。

## 3. 总体几何在早期有预测信息，晚期单批次预测明显退化

全部 checkpoint 来自完整经验训练，未来更新也使用经验目标。
平方模型在第 500/2000/3500 步的单步符号概率分别约 91.8%/57.0%/52.6%；
恒预测风险降低的对应基线约 55.6%/47.7%/50.8%。
第 2000 步重复批次均值的方向吻合率约 92.3%，但单个批次仅 57.0%。

因此不能把先前总体 checkpoint 上的 91.4% 当成整段经验训练的统一性能。
8/64 步概率提高可包含噪声平均；同一中点的风险幅度预测 MAE 则从约 1.2e-5 增至约 6.7e-4，
不能解释成窗口越长一阶展开越准确。

阈值存在与否另列：x_high 的平方总体正阈值在第 500 步出现于 5/10 个状态，
第 2000/3500 步各只有 1/10 个；条件平均绝对 log10 误差约 0.247/0.906/1.032，
后两个值分别只针对一个适用种子。
不主张精确定位最佳配比，也不强迫无正阈值状态能够被反转。
预测仍使用已知任务方向 beta，尚不是无需标签的训练控制方法。

## 4. CIFAR-10 外推较弱

用户提供的确为标准 CIFAR-10 Python 版本：50k/10k、32×32 RGB、十类，七文件校验值一致。
正式使用灰度、64 通道 11×11 valid 卷积、平方、GAP、8 维 head，无额外正则或归一化层。
五个配对种子，每条件 4000 更新，约 22.8 个训练集遍历；这是本机有限预算外推，非收敛结果。

| 配比 | encoder 测试准确率 | projection 测试准确率 |
|---|---:|---:|
| 0.1 | 36.48% | 23.39% |
| 1 | 36.45% | 23.50% |
| 10 | 36.52% | 23.81% |

固定步数下，projection 的 r=10 相对 r=0.1 均值约高 0.43 个百分点。
但共同校准能量 ell=2 的验证差异仅约 +0.11 个百分点，五种子 bootstrap 描述区间约 [-0.42,+0.54]，
其他两个共同能量的 projection 差异区间也跨零。
encoder 差异很小，当前不足以建立自然图像上超出训练速度的稳定收益或稳定退化。
校准能量是固定无标签图像集上的代理，首次穿越网格为 10 步，实际超调量已记录。

训练、checkpoint 和预算均预设；所有训练结束后才统一做固定最终步的测试，未按测试标签选配比或停止点。
Windows 数值评估后的图形汇总遇到 OpenMP 冲突，已拆为独立进程；逐条件数值结果保存且可缓存复用。
